# Stick-figure reel audio

`tech-bed.mp3` is an original synthesized instrumental loop made for the demo.

The short effects are installed locally and ignored by Git. To set up another computer, obtain the clips from their source pages and save them as `pop.mp3`, `chime.mp3`, and `sweep.mp3`, respectively:

- [Minimal Pop Click UI 1 by floraphonic](https://pixabay.com/sound-effects/film-special-effects-minimal-pop-click-ui-1-198301/)
- [UI Loading End Success by SoundShelfStudio](https://pixabay.com/sound-effects/film-special-effects-ui-loading-end-success-522861/)
- [Fast Digital Transition and UI Pop Notification by Chrysalyn](https://pixabay.com/sound-effects/technology-fast-digital-transition-and-ui-pop-notification-540974/)
